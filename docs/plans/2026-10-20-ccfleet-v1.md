# ccfleet v1

A terminal board for every live Claude Code session in tmux: who is working, who needs
you, and what each one is doing. Jump to a pane, peek at it, and find collisions between
agents.

## Data sources (read-only, no hooks required)

| Source | Gives |
|---|---|
| `~/.claude/sessions/<pid>.json` | pid, sessionId, cwd, name, `status` (busy, idle, waiting, shell), `statusUpdatedAt`, `tmux` = `session:@window.%pane` |
| `~/.claude/projects/*/<sessionId>.jsonl` | `ai-title`, `last-prompt`, `gitBranch`, last `tool_use`, `usage` (context size), Edit/Write file paths |
| `~/.claude/teams/*/config.json` | team name, lead session, teammates by `tmuxPaneId` |
| `tmux list-panes -a` | which panes exist and which are visible |

`status: waiting` was confirmed by probing a live permission prompt (2026-10-20).
These files are internal to Claude Code, so each one is parsed in a single adapter.

Liveness: the session file exists, `kill -0 pid` succeeds, and the process is named `claude`.
Transcripts are tailed by byte offset and only re-read when their mtime changes.

## State model

| State | Rule | In "needs you" |
|---|---|---|
| waiting | status = waiting (permission or question) | yes |
| done | idle, and it went idle after you last saw it | yes |
| working | busy or shell | no |
| idle | idle and seen | no |

"Seen" means any of these: the pane is visible on an attached client, you jumped to it via
ccfleet, you dismissed it with `x`, or the `@ccfleet_seen` pane option is newer (set by an
optional tmux focus hook). On first run, every session that is already idle counts as seen.

**No alarms.** The needs-you list is a quiet queue sorted by how long each session has
waited. `ccfleet badge` puts a count in the tmux status line. There are no notifications in v1.

## Collisions (v1)

- **file:** two live sessions with the same git toplevel edited the same file in the last 30 minutes.
- **branch:** two or more sessions in the same checkout are working on the same branch. This one is informational only.

## Commands

- `ccfleet`: the TUI board. Run it with `tmux display-popup -E -w 90% -h 85% "ccfleet --client #{client_tty}"`
- `ccfleet ls [--json]`: a scriptable snapshot
- `ccfleet badge`: a short string for tmux `status-right`
- `ccfleet tmux-snippet`: prints the bindings and the focus hook to paste into tmux.conf

## Keys (vim style)

`j/k`, `gg/G`, `C-d/C-u` move · `/` filters (Esc clears) · `]`/`[` move to the next or previous session that needs you ·
`Enter`/`o` jumps · `p` toggles peek · `l`/`h` focus the peek or list pane (j/k/gg/G/C-d/C-u scroll the peek) ·
`x` marks a session seen · `t` cycles grouping (state, window, repo) · `?` help · `q` quit
